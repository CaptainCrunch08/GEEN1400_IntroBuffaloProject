# GEEN1400_IntroBuffaloProject
Intro project code for GEEN 1400 written for Arduino in C++. This code uses the light input of a photoreceptor to trigger a loop that controls the timing of NeoPixel LEDs and a DC motor such that they both accelerate in speed until all but one LED is lit. The last LED will blink every half second 5 times before the code stops and resets.
