# GEEN1400-BuffaloIntroProject

[![Last commit](https://img.shields.io/github/last-commit/CaptainCrunch08/GEEN1400_IntroBuffaloProject)](https://github.com/CaptainCrunch08/GEEN1400_IntroBuffaloProject/commits/main)

This is Arduino/C++ code for a buffalo sculpture that reacts to light.



This code uses the light input of a photoreceptor to trigger a loop that controls the timing of NeoPixel LEDs and a DC motor such that they both accelerate in speed until all but one LED is lit. The last LED will blink every half second 5 times before the code stops and resets.
